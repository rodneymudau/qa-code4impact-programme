# Course Structure Notes

## Format

- 12 weeks, 2 sessions per week, 60 minutes per session, fully online
- Plain language throughout — no unexplained jargon, South African context and examples (Takealot, Capitec, Uber, load-shedding, eHome Affairs, etc.)
- Goal: take a learner from zero testing experience to a hireable manual + automation QA candidate

## Known Roadmap (update as weeks are confirmed)

| Week | Planned Focus |
|------|----------------|
| 1 | Tester mindset, SDLC/STLC, exploratory testing |
| 2 | Types of testing (functional/non-functional, black box/white box), writing test cases, BRD-to-test-case vocabulary |
| 3 | Bug reporting, the defect life cycle |
| 4+ | Test case design techniques, test plans in depth, then transitioning into automation tooling (planned for later weeks) |

This table reflects what's been explicitly planned in facilitator guides so far ("Looking Ahead" sections) — treat anything beyond Week 3 as provisional until a facilitator guide confirms it.
