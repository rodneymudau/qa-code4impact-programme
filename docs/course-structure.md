# Course Structure Notes

## Format

- 12 weeks, 2 sessions per week, 60 minutes per session, fully online
- Plain language throughout — no unexplained jargon, South African context and examples (Takealot, Capitec, Uber, load-shedding, eHome Affairs, etc.)
- Goal: take a learner from zero testing experience to a hireable manual + automation QA candidate

## Known Roadmap (update as weeks are confirmed)

| Week | Planned Focus |
|------|----------------|
| 1 | Tester mindset, SDLC/STLC, exploratory testing |
| 2 | Types of testing (functional/non-functional, black box/white box), writing test cases, BRD-to-test-case vocabulary |
| 3 | Bug reporting, the defect life cycle |
| 4+ | Test case design techniques, test plans in depth, then transitioning into automation tooling (planned for later weeks) |

This table reflects what's been explicitly planned in facilitator guides so far ("Looking Ahead" sections) — treat anything beyond Week 3 as provisional until a facilitator guide confirms it.

## Session Design Pattern

Each facilitator guide follows the same scripted format, established in Week 1:

- **Session at a Glance** — duration, focus, outcome
- **Before You Start — Setup Checklist**
- Minute-by-minute sections with **SAY THIS** (yellow, near-verbatim) and **DO / FACILITATOR ACTION** (blue, stage directions)
- **If Things Go Wrong — Quick Scripts** — pre-written responses to common live-session hiccups (silence, disagreement, tech issues, load-shedding)
- **Looking Ahead** — sets up the next session, and is the source of truth for what topic comes next

Keeping this structure consistent means a new facilitator can pick up any session cold and run it confidently.

## Student Guide Pattern

Starting Week 2, each week gets one combined Student Guide (not per-day) covering:

1. The week's core teaching content, with definitions and examples
2. Any QA vocabulary introduced that week
3. An Interview Prep section — realistic interview questions tied directly to that week's content, each with a sample answer and a tip

This replaces the earlier pattern of separate per-topic reference handouts, which proved harder for learners to track across multiple files.
